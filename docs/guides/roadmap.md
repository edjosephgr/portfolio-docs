# Roadmap

Portfolio Tracker is currently aligning product delivery with the AI-Driven Framework.

## Active Workstreams

- Framework completion and exception tracking
- Development runtime hardening
- CI quality gates
- API Clean Architecture and Result Pattern migration
- Public documentation and Skills rollout
- Dashboard parity improvements

## Deferred Areas

- Shared package repo, until cross-repo contracts require it
- Public marketing site, until product delivery needs it
- Full hosted quality/security automation, where local-only tooling remains the current boundary

## Release And Versioning

The project uses semantic versioning principles and a coordinated release train for major/minor changes. Patch releases can be repo-specific when compatibility is preserved. Release automation adoption is tracked separately from product behavior.
