# Glossary

| Term | Meaning |
|------|---------|
| Adjusted daily close | Market close value adjusted for corporate actions where applicable |
| ADR | Architecture Decision Record |
| Broker account | A user-owned brokerage account represented with redacted display values |
| Descriptive insight | A statement about observed portfolio data that does not recommend an action |
| Financial PII | Personal or financial information that can identify or expose a user |
| Portfolio | A user-owned grouping of investment activity and metrics |
| Result Pattern | Service pattern where expected failures return explicit result values |
| Spec Kit | Local specification folder with `spec.md`, `plan.md`, and `tasks.md` |
| Work Item | Governed unit of work represented locally and in GitHub |
| Pending | Product state used when required source records or market data are missing |
| Partial | Product state used when only part of the required source coverage is available |
