# Roadmap

Portfolio Tracker actualmente alinea entrega de producto con el AI-Driven Framework.

## Workstreams Activos

- Finalización del framework y tracking de excepciones
- Hardening del runtime de desarrollo
- CI quality gates
- Migración API Clean Architecture y Result Pattern
- Documentación pública y rollout de Skills
- Mejoras de paridad del dashboard

## Áreas Diferidas

- Repo de paquete compartido, hasta que contratos cross-repo lo requieran
- Sitio público de marketing, hasta que la entrega de producto lo necesite
- Automatización hosted completa de calidad/seguridad, donde tooling local-only sigue siendo el límite actual

## Release Y Versioning

El proyecto usa principios semantic versioning y un release train coordinado para cambios major/minor. Patch releases pueden ser específicos por repo cuando se preserva compatibilidad. La adopción de release automation se rastrea separadamente del comportamiento del producto.
