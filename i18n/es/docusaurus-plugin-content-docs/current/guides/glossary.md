# Glosario

| Término | Significado |
|---------|-------------|
| Adjusted daily close | Valor de cierre de mercado ajustado por acciones corporativas cuando aplica |
| ADR | Architecture Decision Record |
| Broker account | Cuenta brokerage propiedad de un usuario representada con valores display redacted |
| Descriptive insight | Declaración sobre datos observados del portafolio que no recomienda una acción |
| Financial PII | Información personal o financiera que puede identificar o exponer a un usuario |
| Portfolio | Agrupación propiedad de un usuario con actividad de inversión y métricas |
| Result Pattern | Patrón de servicio donde fallas esperadas retornan valores de resultado explícitos |
| Spec Kit | Carpeta local de especificación con `spec.md`, `plan.md` y `tasks.md` |
| Work Item | Unidad gobernada de trabajo representada localmente y referenciada en GitHub |
| Pending | Estado del producto usado cuando faltan registros fuente o market data requeridos |
| Partial | Estado del producto usado cuando solo parte de la cobertura fuente requerida está disponible |
